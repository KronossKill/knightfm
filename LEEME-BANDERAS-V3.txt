        npm install flag-icons
    (Si te saltas este paso, la web NO compilará.)

  PASO 2 — Extraer el ZIP:
    Extrae TODO el contenido del ZIP encima de
    D:\Programacion\knightfm
    (sobrescribe archivos: es lo esperado)
    COMPRUEBA QUE VEAS supabase-banderas.sql en la raíz del ZIP.

  PASO 3 — Ejecutar el SQL en Supabase (OBLIGATORIO):
    a) Entra a supabase.com → tu proyecto
    b) Menú lateral: SQL Editor → New query
    c) Abre el archivo supabase-banderas.sql (del ZIP),
       copia TODO su contenido y pégalo
    d) Pulsa RUN (o Ctrl+Enter)
       DEBES VER: una tabla con 2 filas mostrando
       "IpLink country" y "Presence country"
    (Es idempotente: si ya lo habías ejecutado, no pasa nada.)

  PASO 4 — Subir a producción:
        git add .
        git commit -m "fix: banderas pais v3 (SQL + CSP flagcdn)"
        git push
    Espera el deploy de Vercel (1-2 min).

  PASO 5 — Entrar y verificar:
    a) Entra a https://knightfm.vercel.app con tu cuenta
       y pulsa Ctrl+F5 (recarga forzada).
       DEBES VER: tu bandera (Cuba) justo a la derecha de
       tu nombre "kronoss2803".
    b) Junto al contador "N en línea": la(s) bandera(s) de los
       países conectados en ese momento.
    c) (Opcional, comprobación técnica) Pulsa F12 → pestaña
       Console → si escribes:
         document.querySelector("img[src*='flagcdn']")?.src
       DEBES VER una URL de flagcdn (no un error CSP).
