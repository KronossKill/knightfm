COMO APLICARLO EN WINDOWS, PASO A PASO
--------------------------------------
1) Descarga el zip -> clic derecho -> "Extraer todo..." en una carpeta
   temporal (ej. Escritorio\redisenyo106).
2) Copia LAS CARPETAS COMPLETAS (src, public, docs, scripts) y los archivos
   CHANGELOG.md y docs sobre D:\Programacion\knightfm y acepta REEMPLAZAR.
   - Se actualizan unicamente los 50 archivos de la lista del zip.
   - Tu .env, base de datos y descargas NO se tocan.
3) PowerShell en D:\Programacion\knightfm:
      npm install
      npm run dev
   DEBES VER: "Ready" sin errores.
4) Si en tu navegador las imagenes de instalaciones se ven "viejas", pulsa
   Ctrl+F5 (la cache local guarda la respuesta anterior; el servidor ya
   sirve las nuevas y en produccion se refrescan solas).
5) Sube a tu repositorio y despliega a Vercel:
      git add -A
      git commit -m "Redisenyo visual v9.5.0"
      git push
   DEBES VER en Vercel: deployment "Ready".
6) Verifica en produccion (escritorio 1440x900 y movil 390 px):
   - Menu: item activo con barra lima; colapsalo y pasa el raton -> tooltip.
   - Clasificacion: columna FORMA con puntos verdes/grises/rojos.
   - Instalaciones: fotos 16:9 nuevas; si inicias una obra (propietario):
     anillo ambar + 5 fases + cuenta atras.
   - Tesoreria: minigrafo de tendencia del saldo junto al libro mayor.
