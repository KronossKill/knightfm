SISTEMA DE INVERSIONES / DEPÓSITOS (v3, incluido)
─────────────────────────────────────────────────
La cartera (CARTERA → "Depositar $Knight") muestra la DIRECCIÓN
DE DEPÓSITO DEL SISTEMA + CÓDIGO QR + botón "Copiar dirección".
Comprobaciones automáticas del servidor (11 en total):
  ✓ La transferencia debe ir EXACTAMENTE a la billetera del
    sistema (DEST_OWNER_MATCH): si no, el depósito SE RECHAZA.
  ✓ Uso ÚNICO: cada firma solo puede acreditarse una vez
    (anti-replay con candado en base de datos).
  ✓ Token correcto (mint), importe entero positivo, transacción
    exitosa y finalizada, antigüedad ≤ 7 días, etc.

PARA ACTIVAR DEPÓSITOS EN PRODUCCIÓN (tú, como ADMIN):
  Control Center → Configuración → grupo "solana":
    1) solana.rpc.url        → tu endpoint JSON-RPC (Helius,
                               QuickNode u otro proveedor Solana).
    2) solana.mint           → el mint SPL de tu token $Knight.
    3) solana.systemWallet   → la dirección de la BILLETERA DEL
                               SISTEMA que recibe los depósitos.
Mientras rpc.url esté vacío, el botón Depositar responde
honestamente "no configurada" y NO acredita nada.
