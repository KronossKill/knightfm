QUE ES ESTE PAQUETE
-------------------
Este zip NO es una instalacion completa. Contiene UNICAMENTE los
archivos nuevos o modificados del sistema de diseno UI/UX v2.0

D:\Programacion\knightfm ya existente y funcional.

QUE INCLUYE
-----------
1) FUNCIONES NUEVAS EN EL JUEGO
   - Widget "Pulso mundial" en el dashboard (el mundo vivo:
     paises conectados, ultimos resultados del mundo, proximos
     partidos) + su API nueva (src/app/api/world/pulse/route.ts)
   - 4 widgets nuevos: Top plantilla (Manager); Resumen de
     plantilla, Contrato del manager y Riesgo de insolvencia
     (Owner)
   - Paleta de comandos Ctrl+K v2.0: favoritos con estrella
     (max. 8) y navegacion en pila (Backspace para volver)
   - Deep linking: la pantalla abierta queda en la URL (?view=),
     se puede compartir y recuerda donde estabas
   - 5 temas con tokens verificados WCAG AA (115 pares, 0
     fallos); el tema "Verde Clasico" ahora es tema CLARO real
   - Entregables de temas en docs/ui/themes/ (JSON + CSS + TS)
2) DOCUMENTACION ACTUALIZADA: 10 especificaciones en docs/ui/
   (design system, navegacion, dashboard, tactical board, temas,
   componentes, responsive, accesibilidad, rendimiento,
   arquitectura + checklist de calidad v2.0)
3) GUIA NUEVA: docs/GUIA-DESPLIEGUE-GITHUB-SUPABASE.md
   (paso a paso para GitHub + Supabase + Vercel sin perder datos)
4) HERRAMIENTAS: scripts/verify-wcag-contrast.mjs (verificador
   WCAG, listo para CI) y scripts/export-theme-deliverables.mjs
   (regenera docs/ui/themes/ desde los tokens)
5) next.config.ts: los zips ahora tambien se pueden descargar
   pegando su nombre en la raiz del sitio (redireccion a
   /downloads/)

COMO INSTALARLO (WINDOWS, 2 minutos)
------------------------------------
PASO 1  Si el servidor esta abierto, detenlo con Ctrl + C.
PASO 2  Clic derecho sobre este zip -> "Extraer todo...".
PASO 3  En Destino escribe exactamente:
          D:\Programacion\knightfm
        y pulsa "Extraer".
PASO 4  Si Windows pregunta "Reemplazar u omitir": elige
        "Reemplazar los archivos de destino".
PASO 5  Abre la terminal en D:\Programacion\knightfm y ejecuta:
          npm run dev
        Abre http://localhost:3000

DEBES VER: el juego arranca igual que siempre; en el dashboard
aparece el widget "Pulso mundial"; Ctrl+K abre la paleta y con
la estrella fijas favoritos.

IMPORTANTE - NO MEZCLES CARPETAS
--------------------------------
- NO extraigas este zip dentro de una carpeta nueva vacia: va
  ENCIMA de tu carpeta existente.
- NO extraigas zips nuevos ENCIMA de instalaciones viejas
  mezcladas: los archivos sobrantes de versiones viejas rompen
  builds. Si algun dia ves errores raros al compilar, reconstruye
  la carpeta limpia con el zip completo (metodo knightfm-RESERVA).

DESPUES DE INSTALAR: GITHUB + VERCEL
------------------------------------
Abre docs/GUIA-DESPLIEGUE-GITHUB-SUPABASE.md y sigue sus fases.
Resumen rapido (desde D:\Programacion\knightfm):
  git add -A
  git commit -m "UI/UX v2.0: World Pulse, widgets nuevos, paleta v2, temas WCAG"
  git push
Vercel redespliega solo y queda en verde. Tu base de datos de
Supabase NO se toca: git y Vercel nunca borran datos. Los unicos
3 comandos peligrosos siguen siendo: seed --force, db:reset y
"Reset mundo" en admin.
