QUÉ INCLUYE (resumen de las 4 mejoras)
──────────────────────────────────────
1) TASK 76 — SCHEMA DE PRODUCCIÓN POSTGRESQL (CRÍTICO)
   prisma/schema.prisma ya viene como variante PostgreSQL
   (Supabase), validada. Esto fue lo que arregló los errores 500
   de Vercel ("the URL must start with the protocol file:").

2) TASK 77 — SALARIO AUTOMÁTICO DE LOS DOMINGOS
   La nómina se paga SOLO cada DOMINGO a las 01:00 hora del
   servidor (UTC), automáticamente, con vercel.json (cron) +
   endpoint protegido. Paga jugadores + personal + mánager una
   sola vez por domingo, nunca doble pago, y si Vercel se salta
   un domingo lo recupera solo. En Tesorería hay un aviso fijo
   con el horario.

3) TASK 78 — ECONOMÍA CONGELADA + ENTRENAMIENTO SIN FÓRMULA
   • Clubes del sistema SIN mánager y SIN propietario: economía
     INMÓVIL (no pagan ni cobran nada, ni acumulan deuda). En
     cuanto consiguen mánager o propietario, rigen las reglas
     escritas normales.
   • El entrenamiento muestra SOLO las áreas mejoradas y su
     cantidad (ej.: "Técnica +12 · Física +8"). Sin fórmulas.
   • Extra: un camino viejo del cierre de subastas que acreditaba
     dinero sin que nadie pagara fue eliminado (un solo camino
     honesto: el ganador PAGA).

4) TASK 79 — FACTOR DE TALENTO POR ESTRELLAS
   Las estrellas definen lo RÁPIDO que se aprende:
      1★ → 60%   ·  2★ → 80%   ·  3★ → 100%
      4★ → 120%  ·  5★ → 150%
   Un 5★ adquiere habilidades 2.5× más rápido que un 1★ con la
   misma sesión y el mismo club. Los techos no cambian. Los 5
   factores son configurables en Panel de Control → Configuración
   (grupo training: training.talent.star1 ... star5).

5) TASK 81 — PANEL DE DESCARGAS EN LA PÁGINA PRINCIPAL
   Al pie de la página principal (cierra sesión si hace falta)
   hay ahora una sección "Paquetes de actualización" que lista
   AUTOMÁTICAMENTE todos los zips entregados, el más reciente
   destacado arriba con la etiqueta "Más reciente". Desde ahí
   se descarga cualquier paquete con UN CLIC — ya no hace falta
   escribir direcciones a mano. Cada zip nuevo que publiques
   aparecerá ahí solo.

PASOS (en orden, sin saltarte ninguno)
──────────────────────────────────────
PASO 1 — Descarga el paquete
   Descarga: knightfm-acumulativo-fixlogin500-tasks76-79.zip
   (bájalo a tu PC, por ejemplo a Escritorio).

PASO 2 — Detén el servidor local si está corriendo
   En la ventana de terminal del proyecto (PowerShell en
   D:\Programacion\knightfm), pulsa Ctrl+C si el servidor está
   corriendo. No hace falta cerrar la ventana.

PASO 3 — Extrae el ZIP ENCIMA de tu proyecto
   1. Clic derecho sobre el zip → "Extraer todo..."
   2. Como destino escribe EXACTAMENTE:
        D:\Programacion\knightfm
   3. Marca "Reemplazar los archivos en el destino" si Windows
      lo pregunta. Debe extraer 37 archivos en sus carpetas.

PASO 4 — Regenera el cliente de Prisma
   En la terminal del proyecto:
        npx prisma generate
   DEBES VER al final:
        ✔ Generated Prisma Client (v...)
   (El schema incluido es el de PRODUCCIÓN PostgreSQL YA
    VALIDADO. NO ejecutes prisma db push ni prisma migrate.)

PASO 5 — (OPCIONAL) Limpieza en Supabase
   En el SQL Editor de Supabase, ejecuta la línea que está en
   supabase-salario-domingos.sql (borra una configuración vieja
   que ya no se usa). Es IDEMPOTENTE: si ya la ejecutaste o
   nunca existió, no pasa nada. Si nunca tocaste Supabase a
   mano, puedes saltarte este paso.

PASO 6 — Prueba en local
        npm run dev
   Entra con tu mánager y comprueba:
   • ENTRENAMIENTO → ejecuta una sesión → el aviso muestra solo
     áreas + cantidades (los jugadores con más estrellas suben
     más por sesión).
   • TESORERÍA → aparece el aviso del horario de nómina
     ("cada domingo a las 01:00 hora del servidor (UTC)").
   • PÁGINA PRINCIPAL (sin iniciar sesión) → baja al pie → la
     sección "Paquetes de actualización" lista todos los zips,
     con el más reciente destacado como "Más reciente".

PASO 7 — Sube TODO a GitHub para que Vercel despliegue
   En la terminal del proyecto, uno por uno:
        git add .
        git commit -m "Tasks 76-81: schema postgres, salario de domingos, economia congelada, talento por estrellas, panel de descargas"
        git push
   Espera el deploy de Vercel (1-3 min) y prueba en producción
   con Ctrl+F5.

   IMPORTANTE — vercel.json: este paquete lo incluye. Si en tu
   repositorio ya existía un vercel.json con otros cron jobs,
   este lo reemplaza (ahora tiene SOLO el cron del salario de
   los domingos, "0 1 * * 0").
